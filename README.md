# Cartas de Documentos — Releases

Instaladores y notas de versión de la aplicación **Cartas de Documentos**.

La aplicación instalada se actualiza automáticamente desde estos releases.
El código fuente vive en un repositorio privado.

## Instalación

Descargá el instalador de la última versión desde
[Releases](https://github.com/Niihuel/cartas-documentos-releases/releases):

- **Windows**: `Cartas-de-Documentos-Setup-X.Y.Z.exe`
- **Linux**: `Cartas-de-Documentos-X.Y.Z.AppImage`
